# 光脉智瞳

## 长春城市交互演示

访问 `city.html`，可从首页“长春演示”或 SaaS 页面进入。演示以南湖、人民大街和伊通河一带为背景，支持三维旋转缩放、俯视地图、管网和桥梁点选、类型筛选、名称搜索、图层开关、合成振动波形、时频示意、人工复核、模拟工单以及记录和城市画面导出。

路演操作：选择“卫星路燃气示意段” → 触发“施工扰动” → 查看候选事件里程和波形 → 标记已复核 → 生成模拟工单 → 模拟现场确认并关闭。车辆通行作为背景记录，不生成风险工单。桥梁为扩展场景，仅展示振动观测流程。

模型地名用于长春场景叙事；建筑、管线、光缆路径、资产坐标、监测与工单全部为示意或模拟。未接入真实长春管网、客户监测或市政系统。三维渲染库已打包到本地，不需要地图密钥或 CDN 运行时请求。

本地预览：在仓库目录运行 `python -m http.server 8765`，访问 `http://localhost:8765/city.html`。ES 模块需通过 HTTP 服务器打开，不能直接双击 HTML。部署到 GitHub Pages 后可直接访问。细节见 [演示说明](CITY-DEMO.md)。

基于分布式光纤传感与深度学习的城市生命线智能监测系统。

## 技术路线

光纤原始信号 → 预处理(去噪/FFT) → 特征提取(频域能量/峭度/峰值频率) → 轻量化分类器(SVM/1D-CNN) → 三级预警输出 → GIS可视化

## 核心指标

- 事件识别准确率：≥93%
